Fixes where mdrun could behave incorrectly
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Fix race condition with stale shift vectors in GPU non-local nonbonded kernel
"""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

With domain decomposition, GPU nonbonded interactions, GPU coordinate
buffer operations and a changing box (e.g., pressure coupling), the
non-local nonbonded kernel could use the shift vectors from the previous
step, leading to incorrect forces between local and non-local atoms
interacting across a periodic boundary. The effect is expected to be minor
in well-equilibrated systems.

:issue:`5724`

Fix race condition with GPU graphs and x/v output
"""""""""""""""""""""""""""""""""""""""""""""""""

With CUDA/SYCL graphs enabled, on non-graph steps following a graph step, the coordinates
and velocities copied back to the host for trajectory output could be stale. This was
caused by the graph and non-graph streams not being in sync, and could potentially
cause wrong dynamics. However, it is unlikely that this has happened in practice.

:issue:`5833`
